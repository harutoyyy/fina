## 1. このシステムでできること

### システムの概要

「経理くん」は、グループ会社12社の資金（お金の流れ）をまとめて管理するためのシステムです。

日々の経費、売上、原価（仕入れの支払い）、給与などの入出金データを入力・管理し、各会社の口座にいくら入って、いくら出て、いま残高がいくらあるかを一覧で把握できます。

### 誰が使うものか

このシステムには2つの役割（権限）があります。

| 役割 | できること |
|------|----------|
| 経費入力者（一般ユーザー） | 経費の入力、証憑（請求書などの添付ファイル）のアップロード、自分が入力した経費の確認 |
| 管理者 | すべての操作が可能。経費や売上の「確定」、月締め処理、マスタデータ（基本情報）の管理など |

### 何のために使うものか

- 各会社の経費・売上・原価・給与などの入出金データを入力する
- 資金繰り表で「いつ・いくら・入出金があるか」を確認する
- 月ごとにデータを締めて確定する
- 会社間のお金の移動を記録・管理する
- 借入金やリース契約の返済スケジュールを管理する
- 定期的に発生する支払いを自動生成する

## 2. 利用前に知っておくこと

### ログインについて

このシステムを使うには、ログインが必要です。メールアドレスとパスワードでログインします。

アカウントを持っていない場合は、新規登録画面からアカウントを作成できます。パスワードは **8文字以上** で設定してください。

### 事前に準備するもの

- ログイン用のメールアドレスとパスワード
- 入力する経費の請求書や領収書（証憑として添付するため）
- 入力する取引の情報（日付、金額、相手先など）

### 利用時の注意点

- **会社の選択を忘れずに：** 画面左上の会社選択で、操作対象の会社を選んでから作業してください。選び忘れると、意図しない会社のデータを操作してしまう可能性があります。
- **月締め後の制限：** 月締め処理を行った月のデータは、金額の変更や取消ができません。摘要（メモ）や科目の変更は可能です。
- **金額の入力ルール：** 金額は円単位で入力します。支出（出ていくお金）は自動的にマイナスで記録されます。
- **こまめに保存：** 入力途中のデータは自動保存されません。入力が終わったら必ず「保存」を押してください。

## 3. 基本的な使い方

### 最初に何を開くか

ログインすると「ダッシュボード」画面が表示されます。ここが起点（ホーム画面）です。

まだ会社の選択をしていない場合は、画面に初期設定の手順が表示されます。その案内に沿って進めてください。

### 画面の見方

画面は大きく3つの部分に分かれています。

**左側のメニュー（サイドバー）：** 各機能への入り口です。上から順に以下のグループに分かれています。

| メニューグループ | 含まれる画面 |
|----------------|------------|
| メイン | ダッシュボード、資金繰り表、資金移動 |
| 入力 | 経費入力、経費確定BOX、売上入力、原価支払、給与入力 |
| 管理 | 現金引出、借入管理、リース管理、定期テンプレート、月次処理 |
| マスタ | 会社一覧、銀行口座、銀行・支店、取引先、給与グループ、勘定科目、控除カテゴリ、設定 |

**上部のヘッダー：** 会社の切替、テーマ（明るい/暗い画面）の切替、ログアウトができます。

**中央の作業エリア：** 選んだ画面の内容が表示されます。

### よく使うボタンやメニューの意味

| ボタン・表示 | 意味 |
|-------------|------|
| 「下書き」 | まだ確定されていない、入力途中のデータです |
| 「準備完了」 | 必要な情報が揃い、管理者の確定待ちの状態です |
| 「確定済」 | 管理者によって確定されたデータです |
| 「取消」 | 取り消されたデータです。資金繰り表には通常表示されません |
| 「保存」 | 入力した内容を保存します |
| 「編集」（鉛筆のアイコン） | データを修正します |
| 「削除」（ゴミ箱のアイコン） | データを削除します |
| 「＋」ボタン | 新しいデータを追加します |

## 4. 画面ごとの操作方法

### 4.1 ダッシュボード

**この画面でできること：** 選択中の会社の概要を確認できます。

**どんなときに使うか：** ログイン直後に会社の状況をざっと確認したいときに使います。

**表示される情報：**

- 会社名と業種
- 登録済みの口座数
- 登録済みの取引先数
- 今月の取引件数
- メイン口座の残高
- 経費確定待ちの件数と合計金額
- メイン口座の最近の取引一覧

**注意点：** 会社が未選択の場合、初期設定の手順が表示されます。先に会社を選択してください。

---

### 4.2 資金繰り表

**この画面でできること：** 会社・口座・月ごとの入出金の一覧と残高の推移を確認できます。

**どんなときに使うか：** 「今月いくら支払って、いくら入金があって、残高がいくらか」を確認したいときに使います。

**操作手順：**

1. 画面上部で「口座」と「年月」を選びます
2. 選んだ口座・月の取引一覧が表示されます
3. 各行には、日付、取引先、入金額、支払額、差引残高などが表示されます

**主な機能：**

| 機能 | 説明 |
|------|------|
| 月の切替 | 年月セレクターで別の月を選べます |
| 口座の切替 | 口座セレクターで別の口座を選べます |
| 親子明細の展開 | 行の左にある▶をクリックすると、詳細な内訳が表示されます |
| 並べ替え | 取引行をドラッグして表示順を変更できます。残高は自動的に再計算されます |
| 繰り延べ | 取引を「翌月へ繰り延べ」にすると、当月から消えて翌月に表示されます |
| フィルター | 取引先名や金額帯で絞り込みができます |

**注意点：**

- 残高は取引の並び順で計算されます。並べ替えると残高も変わります。
- 月締め済みの月は、金額の変更ができません。

---

### 4.3 資金移動

**この画面でできること：** 会社間、または同じ会社内の口座間でお金を移動する記録を作成できます。

**どんなときに使うか：** グループ会社間でお金を送ったとき、または同じ会社の別口座にお金を移したときに使います。

**操作手順（新規登録）：**

1. 「新規資金移動」ボタンを押します
2. 入力画面が開きます
3. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| グループ会社間振替 | − | チェックを入れると、別の会社への送金になります |
| 振替先会社 | ※ | グループ会社間のときに選択します |
| 移動元口座 | ○ | お金を出す口座を選びます |
| 移動先口座 | ○ | お金を入れる口座を選びます |
| 移動日 | ○ | お金を移動した日を入力します |
| 計上月 | ○ | どの月の記録にするかを選びます |
| 金額 | ○ | 移動する金額を入力します |
| 摘要 | − | メモ（任意） |

4. 「保存」を押します

**注意点：**

- 会社間の資金移動を登録すると、相手の会社にも自動的に取引が作成されます。
- 一方を修正・削除すると、相手側も連動して変更されます。
- 移動元と移動先に同じ口座は選べません。

---

### 4.4 経費入力

**この画面でできること：** 日々の経費（支払い）を入力・管理できます。

**どんなときに使うか：** 請求書が届いたとき、支払いが発生したときに使います。

**画面の構造：** 3つのタブに分かれています。

| タブ | 内容 |
|------|------|
| 臨時 | 不定期に発生する経費を入力します |
| 固定 | 毎月決まった支払い（家賃など）のテンプレートを管理します |
| 変動 | 変動する定期支払いのテンプレートを管理します |

#### 臨時経費の入力手順

1. 「臨時」タブを選びます
2. 画面右上の「新規追加」ボタンを押します
3. 入力画面が開きます
4. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| 口座 | ○ | 支払いに使う口座を選びます |
| 取引先 | ○ | 支払い相手を取引先一覧から選びます |
| 支払日 | ○ | 実際に支払う日を入力します |
| 計上月 | ○ | どの月の経費にするかを選びます |
| 支払方法 | ○ | 「振込」または「引落」を選びます |
| 金額 | ○ | 支払う金額を入力します |
| 勘定科目 | − | 経費の分類を選びます（確定時は必須） |
| 補助科目 | − | 勘定科目の細かい分類を選びます（任意） |
| 摘要 | − | メモ（任意） |

5. 「保存」を押します

**グループ会社間の経費について：** 別の会社への支払いの場合、「グループ会社間振替」にチェックを入れると、相手会社を選択でき、資金移動も自動で作成されます。

**フィルター機能：** 画面上部で計上月やステータスで絞り込みができます。

**一括操作：** 複数の経費にチェックを入れて、まとめてステータスを変更したり削除できます。

#### 固定経費・変動経費のテンプレート

「固定」や「変動」タブでは、毎月や定期的に発生する経費のテンプレート（ひな形）を作成できます。テンプレートを作っておくと、月初の一括生成で自動的に経費データが作られます。

テンプレートの設定項目には、テンプレート名、取引先、科目、支払日ルール、金額タイプ（固定額/変動/手入力）などがあります。

### 4.5 経費確定BOX（受領BOX）

**この画面でできること：** 届いた請求書の受付と経費の準備完了・確定処理ができます。

**どんなときに使うか：** 経費入力者が「必要な情報が揃ったので確認してほしい」と申請するとき、管理者がまとめて確定処理をするときに使います。

**経費入力者の操作手順：**

1. 「経費確定BOX」を開きます
2. 自分が担当する経費の一覧が表示されます
3. 金額・証憑（請求書の添付）・取引先がすべて揃っていることを確認します
4. 「準備完了」ボタンを押します

**管理者の操作手順：**

1. 一覧でステータスが「準備完了」の経費を確認します
2. 内容に問題がなければ「確定」ボタンを押します
3. 修正が必要な場合は「差戻し」ボタンを押します

**フィルター機能：**

| フィルター | 説明 |
|-----------|------|
| 受領日 | 全件、今日、今週、今月から選べます |
| 証憑 | 全件、添付済み、不要、未添付から選べます |
| 取引先 | 名前の一部で検索できます |
| 摘要 | メモの内容で検索できます |
| 予定日 | 日付の範囲で絞り込めます |

**準備完了にできない場合：** 金額、証憑、取引先のいずれかが入力されていないと、準備完了にできません。足りない項目を入力してから再度お試しください。

**証憑の「なしOK」設定：** 管理者のみ、証憑の添付が不要な経費に「なしOK」を設定できます。

### 4.6 売上入力

**この画面でできること：** 売上（請求と入金）の管理ができます。

**どんなときに使うか：** 請求書を発行したとき、入金があったときに使います。

**操作手順（請求の登録）：**

1. 「請求を追加」ボタンを押します
2. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| 口座 | ○ | 入金される口座を選びます |
| 取引先 | ○ | 請求先を選びます |
| 請求日 | ○ | 請求書の日付を入力します |
| 入金予定日 | ○ | 入金される予定日を入力します |
| 計上月 | ○ | どの月の売上にするかを選びます |
| 請求額 | ○ | 請求する金額を入力します |
| 勘定科目 | − | 科目を選びます |
| 摘要 | − | メモ（任意） |

3. 「保存」を押します

**入金の記録：**

1. 売上一覧で該当の請求行にある「入金」ボタンを押します
2. 入金日、入金額などを入力して保存します
3. 分割で入金された場合は、複数回に分けて登録できます

**控除の入力：**

1. 「控除」ボタン、または請求行を展開して「控除内訳を入力」を押します
2. 振込手数料や値引きなどの控除カテゴリを選び、金額を入力します
3. 前月の控除内容をコピーすることもできます（「前月からコピー」ボタン）

**確定の流れ（2段階）：**

| 段階 | 操作者 | 説明 |
|------|-------|------|
| 請求確定 | 入力者 | 請求内容に誤りがないことを確認して確定します |
| 入金・控除確定 | 管理者 | 入金額と控除の整合がとれていることを確認して確定します |

**注意点：**

- 請求金額と、実際の入金合計＋控除合計が一致しないと確定できません。
- 差額がある場合は、一覧の「残額」欄にオレンジ色で表示されます。

---

### 4.7 原価支払

**この画面でできること：** 工事原価（外注先への支払い）を管理できます。

**どんなときに使うか：** 協力会社への支払いが発生したときに使います。

**操作手順（新規登録）：**

1. 「新規登録」ボタンを押します
2. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| 口座 | ○ | 支払いに使う口座を選びます |
| 支払先 | ○ | 取引先を選びます |
| 施工日 | ○ | 工事の日を入力します |
| 計上月 | ○ | どの月の原価にするかを選びます |
| 労務費 | − | 人工にかかった費用 |
| 法定福利 | − | 法定福利費 |
| 材料雑費 | − | 材料費と諸経費 |
| 消費税 | − | 消費税額 |
| 実支払額 | − | 実際に支払った金額 |
| 摘要 | − | メモ（任意） |

3. 「合計」と「差額」は自動計算されます
4. 「保存」を押します

**控除の入力：** 「控除」ボタンから、協力会費、保険料、立替金回収などの控除内訳を入力できます。

**確定の条件：**

- 分割支払い中（未払いが残っている状態）では確定できません
- 支払いが完了した後、差額（計上額−実支払合計）と控除合計が一致して初めて確定できます

---

### 4.8 給与入力

**この画面でできること：** 給与グループ（部門）ごとの給与データを入力・管理できます。

**どんなときに使うか：** 毎月の給与計算が完了し、データを登録するときに使います。

**操作手順（新規入力）：**

1. 「新規給与入力」ボタンを押します
2. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| 給与グループ | ○ | 対象のグループを選びます（例：工事部門、営業部門） |
| 支給日 | ○ | 給与を支払う日を入力します |
| 人数 | ○ | 対象人数を入力します |
| 課税支給 | ○ | 課税対象の支給額を入力します |
| 交通費 | − | 通勤手当を入力します |
| 諸経費 | − | その他の経費を入力します |
| 繰越金調整 | − | 前月からの調整額を入力します |
| 立替経費 | − | 社員の立替分を入力します |

3. 入力すると、以下が自動計算されます：
   - **総支給：** 各項目の合計
   - **社保積立（15%）：** 課税支給額の15%（社会保険料の見込み）
   - **消費税積立（10%）：** 課税支給額の10%（消費税の見込み）

4. 「保存」を押します

**控除の入力：**

「控除」ボタンを押すと、控除項目を行単位で入力できます。家賃控除、通信費控除、各種保険料、所得税、住民税など、項目名と金額を入力します。行の追加・削除も可能です。

**支払内訳の入力：**

「支払内訳」ボタンを押すと、実際の出金の内訳を入力できます。出金日、支払方法（振込/引落/現金引出）、出金口座、金額を行単位で入力します。

**整合チェック：** 以下の2つが一致していないと確定できません。

1. 総支給 − 控除合計 ＝ 差引支給額
2. 差引支給額 ＝ 支払内訳の合計

不一致の場合、一覧に警告が表示されます。

**Excelからの取り込み：** 「Excelインポート」ボタンから、Excel形式のテンプレートファイルを使って一括登録できます。取り込み前に内容のプレビューが表示されるので、確認してから登録してください。

### 4.9 現金引出

**この画面でできること：** 現金で支払う複数の取引をまとめて「現金引出バッチ」として管理できます。

**どんなときに使うか：** 複数の現金支払いをまとめて銀行から引き出すときに使います。

**操作手順：**

1. 「＋」（新規バッチ）ボタンを押します
2. 引出口座、引出日、引出金額を入力して保存します
3. 作成されたバッチに、用途明細（何に使うか）を紐づけます
   - 「明細追加」ボタンで、未割当の現金取引から選択します
4. 必要に応じて「金種表」ボタンで金種内訳（1万円札○枚、千円札○枚…）を入力します
5. すべて確認できたら「確定」を押します

**確定の条件：**

- 引出金額 ＝ 用途明細の合計金額
- 金種表の合計 ＝ 引出金額

**注意点：** 確定後は明細の追加・削除ができません。

---

### 4.10 借入管理

**この画面でできること：** 銀行からの借入契約と返済スケジュールを管理できます。

**どんなときに使うか：** 新しい借入を行ったとき、返済状況を確認したいときに使います。

**操作手順（契約の登録）：**

1. 「新規借入契約」ボタンを押します
2. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| 契約名 | ○ | わかりやすい契約名をつけます |
| 借入先 | − | 取引先から選びます |
| 借入額 | ○ | 借入金額を入力します |
| 実行日 | ○ | 借入を実行した日を入力します |
| 返済開始日 | ○ | 返済を開始する日を入力します |
| 返済方法 | ○ | 元金均等、据置、一括から選びます |
| 返済頻度 | ○ | 月次、四半期、半年、年次から選びます |
| 返済日 | − | 毎月の返済日（1～31日）を入力します |
| 返済回数 | ○ | 総返済回数を入力します |
| 金利タイプ | ○ | 固定金利または変動金利を選びます |
| 金利（%） | ○ | 年利を入力します |

3. 「保存」を押します

**返済スケジュールの確認：**

契約を登録すると、元金・利息・残高の返済スケジュールが自動で作成されます。「詳細」ボタンで確認できます。

各返済について「支払済にする」ボタンで支払い状況を更新できます。

### 4.11 リース管理

**この画面でできること：** リース契約と月々の支払いスケジュールを管理できます。

**どんなときに使うか：** コピー機やPC等のリース契約を登録・管理したいときに使います。

**操作手順（契約の登録）：**

1. 「新規契約」ボタンを押します
2. 契約名、相手先、月額、開始日、終了日、支払日などを入力します
3. 引落口座や勘定科目も設定できます
4. 「保存」を押します

支払いスケジュールが自動で作成されます。「詳細」ボタンから確認でき、「支払済みにする」で状況を更新できます。

スケジュールを作り直したい場合は「スケジュール再生成」ボタンを使います。

### 4.12 定期テンプレート

**この画面でできること：** 毎月の家賃やインターネット料金など、定期的に発生する支払いのテンプレート（ひな形）を作成・管理できます。

**どんなときに使うか：** 毎月決まった支払いを自動で作成したいときに使います。

**テンプレート作成の手順：**

1. 「新規テンプレート」ボタンを押します
2. 以下の項目を入力します

| 入力項目 | 必須 | 説明 |
|---------|------|------|
| テンプレート名 | ○ | わかりやすい名前をつけます（例：○○ビル家賃） |
| 頻度 | ○ | 毎月、隔月、四半期、年次などから選びます |
| 支払日ルール | ○ | 支払日の決め方を選びます |
| 取引種別 | ○ | 経費、売上などを選びます |
| 金額タイプ | ○ | 固定額、変動（前回コピー）、手入力から選びます |
| 固定金額 | ※ | 金額タイプが「固定」のときに入力します |

3. 「保存」を押します

**月次一括生成：**

「月次一括生成」ボタンを押すと、有効なテンプレートから対象月の取引が自動で作成されます。作成された取引は「下書き」状態なので、金額や内容を確認してから確定に進めてください。

**注意点：** テンプレートの「有効」スイッチをオフにすると、一括生成の対象から外れます。

### 4.13 月次処理

**この画面でできること：** 月ごとのデータを「締め」て確定できます。

**どんなときに使うか：** その月のすべての入出金データが確定し、これ以上変更がないときに使います。

**月締めの手順：**

1. 「月次処理」を開きます
2. 一覧から締めたい月をクリックして選択します
3. 画面下部に、その月の口座ごとの残高が表示されます
4. 期首残高が正しいか確認します（必要に応じて修正します）
5. 「月締め実行」ボタンを押します
6. 確認メッセージが表示されたら「締め実行」を押します

**月締めの解除（管理者のみ）：**

1. 締め済みの月を選択します
2. 「月締め解除」ボタンを押します
3. **解除理由を入力します**（必須）
4. 「解除実行」を押します

**注意点：**

- 月締め後は、その月の取引の金額変更・取消ができなくなります
- 摘要（メモ）や科目の変更は、月締め後も可能です
- 解除の操作は管理者のみが行えます
- すべての月締め操作は履歴（監査ログ）に記録されます

### 4.14 マスタ管理

マスタとは、システムで共通して使う基本情報（会社名、口座情報、取引先名など）のことです。

#### 4.14.1 会社一覧

会社の基本情報を確認・編集できます。

**編集できる項目：** 会社名、フリガナ、略称、業種、代表者、住所、連絡先、法人番号、インボイス番号、決算月、ステータスなど

#### 4.14.2 銀行口座

会社ごとの銀行口座を管理します。

**操作手順（口座の追加）：**

1. 画面上部で会社を選択します（必須）
2. 「口座追加」ボタンを押します
3. 銀行名、支店名、口座番号、種別（普通預金/定期預金）、口座名義を入力します
4. メイン口座にする場合はチェックを入れます
5. 「保存」を押します

**注意点：**

- 会社を登録すると、仮想口座（社会保険積立・消費税積立）が自動で2つ作られます
- メイン口座は通常1つです
- 口座を使わなくなった場合は「無効化」します（削除はできません）

#### 4.14.3 銀行・支店マスタ

銀行名と支店名の一覧を管理します。初回は「主要銀行一括登録」ボタンで全国の主要銀行を一括で登録できます。

画面左で銀行を選ぶと、右に支店一覧が表示されます。検索ボックスで銀行名や支店名を検索できます。

#### 4.14.4 取引先

取引先（支払い先や請求先）の情報を管理します。

**操作手順（取引先の追加）：**

1. 「取引先追加」ボタンを押します
2. 取引先名、フリガナ、種別（請求先/支払先/双方）、タグを入力します
3. 「保存」を押します

**振込先口座の登録：** 取引先を選択すると、画面下部に振込先口座を追加できます。銀行コード、支店コード、口座番号、口座名義カナを入力します。

**デフォルト科目の設定：** 取引先にデフォルトの勘定科目を設定しておくと、経費入力時に自動で科目がセットされます。

**契約/地点テンプレ：** 取引先配下に、物件ごとの定期支払い設定を登録できます（家賃など）。

**注意点：** 取引データがある取引先は削除できません。使わなくなった場合は「無効化」してください。

#### 4.14.5 給与グループ

会社ごとの給与グループ（部門区分）を管理します。

設定項目：グループ名、コスト種別（原価/販管費/外注）、人数、支払日、休日調整、振込口座、現金引出口座

#### 4.14.6 勘定科目

経費や売上の分類に使う科目を管理します。3つの階層で構成されています。

| 階層 | 説明 | 例 |
|------|------|-----|
| 大項目 | 損益計算書の区分 | 販売管理費、売上原価、営業外費用 |
| 中項目 | 勘定科目 | 通信費、地代家賃、水道光熱費 |
| 小項目 | 補助科目（任意） | 電気代、ガス代、水道代 |

大項目の左にある▶をクリックすると中項目が展開され、中項目の▶をクリックすると小項目が表示されます。

「中項目追加」「＋」ボタンで項目を追加できます。使わなくなった科目は「利用停止」にできます（削除はできません）。

#### 4.14.7 控除カテゴリ

売上や原価の控除（差し引き）に使うカテゴリを管理します。「売上控除」タブと「原価控除」タブに分かれています。

カテゴリ名とデフォルトの科目を設定します。「発生/相殺の小項目を持つ」にチェックを入れると、前倒し入金や保留金の管理ができます。

#### 4.14.8 設定

現在準備中の画面です。将来的に追加機能が実装される予定です。

## 5. よくある操作

### 新規登録

各画面の「＋」ボタンや「新規○○」ボタンを押すと、入力画面が開きます。必要項目を入力して「保存」を押してください。必須項目（※や＊がついた項目）が入力されていないと保存できません。

### 編集

一覧の各行にある鉛筆アイコン（編集）ボタンを押すと、入力画面が開きます。変更したい項目を修正して「更新」を押してください。

月締め済みの月のデータは、金額の変更ができません。

### 削除

ゴミ箱アイコンまたは「削除」ボタンを押すと、確認メッセージが表示されます。「OK」を押すとデータが削除されます。

以下の場合は削除できません：
- 取引データが紐づいているマスタ（取引先、科目など）
- 確定済みの取引（月締め済みの月のデータ含む）
- 確定済みの現金引出バッチ

### 検索・絞り込み

各画面のフィルター欄を使って、表示するデータを絞り込めます。計上月、ステータス、取引先名、金額帯などで絞り込みが可能です。

### ファイルのアップロード（証憑添付）

経費入力で証憑（請求書や領収書）を添付する手順：

1. 対象の経費の「証憑」ボタンを押します
2. 「ファイルを添付」ボタンを押します
3. ファイルを選択します（画像、PDF、Excel、CSVに対応）
4. アップロードが完了すると、ファイル名が表示されます
5. アップロードしたファイルは、目のアイコンでプレビューできます

### 準備完了・確定の流れ

多くのデータは以下の3段階で進みます：

```
下書き → 準備完了 → 確定済
```

1. **下書き：** 入力直後の状態です。自由に編集・削除できます。
2. **準備完了：** 必要な情報が揃った状態です。入力者が「準備完了」ボタンを押します。
3. **確定済：** 管理者が内容を確認して「確定」ボタンを押した状態です。

管理者は、問題がある場合「差戻し」で下書きに戻すことができます。

## 6. エラーが出たときの対処

### 入力エラー

| エラーの状況 | 対処方法 |
|-------------|---------|
| 「パスワードは8文字以上で入力してください」 | パスワードを8文字以上に変更してください |
| 「メールアドレスまたはパスワードが正しくありません」 | メールアドレスとパスワードを確認してください |
| 保存ボタンが押せない / 保存時にエラーが出る | 必須項目（＊印のある項目）がすべて入力されているか確認してください |
| 金額が入力できない | 数字だけを入力してください。カンマや円マークは不要です |

### 権限エラー

| エラーの状況 | 対処方法 |
|-------------|---------|
| 「確定」ボタンが表示されない | 確定は管理者のみの操作です。管理者に依頼してください |
| 資金繰り表が見られない | 経費入力者には表示されない場合があります。管理者に確認してください |

### 操作が制限される場合

| 状況 | 原因と対処 |
|------|----------|
| 金額を変更できない | 月締め済みの月の可能性があります。管理者に月締め解除を依頼してください |
| 取引先を削除できない | その取引先に取引データが紐づいています。「無効化」で対応してください |
| 確定ボタンを押してもエラーになる | 必要な条件（金額の整合、証憑の添付など）が満たされていないか確認してください |
| 科目を削除できない | 使用済みの科目は削除できません。「利用停止」で対応してください |

### 通信エラー

画面に「更新に失敗しました」などのエラーが表示された場合は、ページを再読み込みしてからもう一度操作してください。繰り返し発生する場合はシステム管理者に連絡してください。

### データが見つからない場合

- 正しい会社が選択されているか確認してください
- フィルター（絞り込み）の条件を見直してください
- 別の月に計上されている可能性があります

## 7. よくある質問

**Q. 間違って別の会社のデータを入力してしまいました。**
A. 画面左上の会社切替を確認してください。間違った会社に入力した場合は、そのデータを削除し、正しい会社を選択してから入力し直してください。

**Q. 月締めした後にデータの修正が必要になりました。**
A. 管理者に月締め解除を依頼してください。解除時には理由の入力が必要です。解除後に修正し、再度月締めを行ってください。

**Q. 証憑（請求書）を間違えて添付しました。**
A. 証憑管理画面で、間違ったファイルのゴミ箱アイコンを押して削除し、正しいファイルを再度アップロードしてください。

**Q. 取引先のデフォルト科目を設定したのに反映されません。**
A. 取引先マスタでデフォルト科目が正しく保存されているか確認してください。新規入力のときにのみ自動適用されます。

**Q. 売上の確定ができません。**
A. 以下を確認してください。
- 請求金額 − 入金合計 ＝ 控除合計 になっていますか？（0円差異まで一致が必要です）
- 請求確定（ステップ1）は完了していますか？
- 管理者アカウントでログインしていますか？（入金・控除確定は管理者のみ）

**Q. 給与入力で「整合チェック」のエラーが出ます。**
A. 以下の2つを確認してください。
- 総支給 − 控除合計 ＝ 差引支給額 になっているか
- 差引支給額 ＝ 支払内訳（振込＋現金引出）の合計になっているか

**Q. 定期テンプレートから取引が自動生成されません。**
A. テンプレートの「有効」スイッチがオンになっているか確認してください。また、「月次一括生成」ボタンを押す必要があります。

**Q. 金額の表示に「¥」やカンマがつくのに、入力時にはつけなくてよいのですか？**
A. はい。金額は数字だけを入力してください。表示時には自動で「¥」やカンマがつきます。
