## 1. 経理くんとは

複数会社（グループ会社）の **現金の動き** を一元管理するクラウドシステムです。

### 主にできること

| カテゴリ | 内容 |
|---|---|
| **資金繰り** | 各銀行口座の残高推移を月別・日別に把握 |
| **経費管理** | 請求書受領 → 支払予定登録 → 確定 → 月締めまで一貫管理 |
| **売上管理** | 請求発行 → 入金消込までフォロー |
| **取引先管理** | 取引先・銀行口座情報のマスタ管理 |
| **証憑管理** | 請求書 PDF を取引データに紐付けて保管（電帳法対応） |
| **グループ会社対応** | 複数社をまたいだ資金繰り・連結サマリ |
| **エクセル取込** | 既存の経費・売上データを Excel から一括取込 |
| **FB データ出力** | 全銀協フォーマットで振込データ作成（銀行アップロード用） |

### 紙の現金出納帳との違い

- 入金・支払予定が**事前に登録**でき、未来の残高見通しが立つ
- 取引先・科目別の集計が**自動**
- **複数社合算**で全グループの資金状況が一画面に
- スマホでも閲覧可能（経費の証憑写真撮影など）

## 2. アクセス方法とログイン

### URL

**本番環境**: https://fina-five.vercel.app

### 初回登録

1. 上記 URL の `/register` ページから
2. **氏名・メールアドレス・パスワード** で新規登録
3. 自動的にログイン → ダッシュボードへ

### 通常ログイン

1. `/login` ページからメールアドレス＋パスワードでログイン
2. ログイン状態は **30日間** 保持されます（チェックを外せば都度ログイン）

### パスワードを忘れた場合

現在はパスワードリセット機能未実装のため、管理者にご連絡ください（DB側で再設定が必要）。

## 3. ユーザー権限

3 段階のロールがあります。

| ロール | できること | 想定ユーザー |
|---|---|---|
| **ADMIN（管理者）** | 全機能。マスタ編集・月締め・科目作成・他ユーザー管理が可能 | 経理責任者・システム管理者 |
| **OPERATOR（オペレーター）** | 取引データの入力・編集・証憑添付。マスタ閲覧のみ | 経理担当者 |
| **VIEWER（閲覧者）** | 閲覧のみ。通帳照合点の登録は可能 | 監査担当・経営者 |

### 操作できない場合

- 「**管理者のみ実行できます**」というエラーが出る → ADMIN ロールが必要です
- 月締め解除、マスタ編集、勘定科目追加などは ADMIN のみ
- 閲覧者は登録ボタン自体が出ません

## 4. 画面構成

### サイドメニュー（左側）

カテゴリ別に整理されています:

| カテゴリ | 主な機能 |
|---|---|
| **（無印）** | ダッシュボード / 資金繰り表 |
| **入力** | 経費入力 / 売上入力 / 原価支払 / 給与入力 / グループ間入力 |
| **管理** | 現金引出 / 借入管理 / リース管理 / 納税予定表 / カード明細 / 定期支払 |

### 会社セレクター

各ページの **右上** に会社切替プルダウンがあります。「どの会社のデータを見ているか」がページごとに分かるようになっています。

会社ごとの資金繰り・経費・売上をそれぞれのページで確認する運用です（全社一括の合算ビューは廃止）。

## 5. 機能一覧（メニュー別）

### 5.1 ダッシュボード

ログイン直後に表示される会社ごとの概要画面。

- 口座数・取引先数・今月の取引件数
- メイン口座の残高と直近の入出金
- 経費確定待ち件数
- グループ全体の資金状況タイル

### 5.2 資金繰り表

選択した会社・口座・月の取引を一覧表示する**メイン画面**。

**基本機能:**
- **日付順表示** + 同日同時ルール（引落 → 振込 → 入金の順で並ぶ）
- **差引残高** が行ごとに自動計算
- **ドラッグ&ドロップ並べ替え** で支払順序の入替
- **複数行選択 + 一括翌月繰延**
- **通帳照合点設定**: 「ここまで通帳と一致した」というチェックポイントを行に設定可能
- **編集**: 行ダブルクリックで該当入力画面へ遷移

**サマリーカード（5枚）:**
- 期首残高 / 当月入金合計 / 当月支払合計 / **予測残高（月末）** / 会社情報
- 入金・支払カードには「**内 グループ間**」内訳を併記
- 会社情報カードをクリックすると詳細ダイアログ（法人番号・設立日・資本金・e-Tax 番号・経理担当者など）が開きます

**取引行のバッジ・色付け:**
- **G間** バッジ（紫の左ボーダー）: グループ会社間の取引
- **未達** バッジ（薄色・斜体）: 予定日が過ぎているのに未確定の取引
- 取引種別ラベル（経費・売上・原価・給与・借入・振替）も併記

**印刷・帳票作成:**
- **印刷** ボタン: 表全体をそのまま印刷
- **帳票作成** ボタン: 選択した取引から、用途別の帳票を別ウィンドウで生成 (A4縦)
  - **資金移動帳票**: 自社口座 → 自社の別口座へ資金を動かす取引。明細・合計を表示
  - **振込依頼書**: 取引先口座へ銀行振込する取引。振込先口座情報・件数・振込合計・自社負担手数料
  - **現金支払帳票**: 現金引出で支払う取引。明細・合計 + 金種表（10000/5000/1000/500/100/50/10/5/1円、手書き枠）

#### 帳票作成ボタンが出てこない場合

「帳票作成」ボタンは、取引行のチェックボックスで **1件以上を選択した時だけ** ツールバーに現れます。表示されない時のチェック:

| 状況 | 対処 |
|---|---|
| その月がすでに**月締め済み** | 「月締め解除」してから（ADMIN 権限が必要） |
| 選択行が **0件** | 各行の左端チェックボックスで選びます。ヘッダのチェックボックスで全選択も可 |
| 全部の行が**確定済み** | 確定済みの行は選択対象外です。未確定行を含めて選び直してください |

#### 「種別が混在しています」と表示されたら

> 選択した取引の種別が混在しています。同じ種別（資金移動 / 振込 / 現金）の行のみ選択してください。

このメッセージが出るのは、選んだ取引の **お金の動かし方が揃っていない** ためです。帳票は次の **3 種類しか作れません**。**同じ種類の取引だけを選び直してください。**

| 帳票の種類 | 対象となる取引 | 業務イメージ |
|---|---|---|
| **資金移動帳票** | 自社の口座から自社の別口座への振替 | メイン口座 → 給与専用口座へ資金を移す |
| **振込依頼書** | 取引先口座へ**銀行振込**で支払う取引 | 仕入先 A 社に銀行振込で支払う（売上回収・経費・原価・給与いずれの種別でも可） |
| **現金支払帳票** | **現金引出** で支払う取引 | ATMで現金を下ろして手渡しで払う |

**ありがちな NG パターン:**
- 自社内の口座移動と、取引先への振込を一緒に選んでいる
- 振込で払うものと、現金で払うものを一緒に選んでいる
- 振込の行に **カード払い・自動引落・手形** などが混ざっている（これらは「振込」ではないので一緒にできません）

**コツ:** 取引行の「種別」「支払方法」列を見て、すべて同じ動かし方になっているか確認してから「帳票作成」を押してください。

> **メモ:** 自社内の口座間で資金を動かす取引（振替）は、資金繰り表または取引入力画面で「振替」種別として登録します。専用画面はありません。

### 5.3 経費入力

経費取引の登録・編集。**4 タブ構成**:

| タブ | 用途 |
|---|---|
| **固定** | 毎月決まった金額の支払（家賃、リース料など）。**定期支払**で登録した内容から自動生成 |
| **変動** | 毎月発生するが金額が変動する支払（光熱費、通信費など）。**定期支払**で登録した内容から自動生成 |
| **臨時** | 単発の経費 |
| **受領BOX** | 請求書を受け取った時の最初の入り口。処理待ちの請求書だけを集めた作業ボックス |

**主な機能:**
- 定期支払（テンプレート）からの自動生成（休日調整あり）
- 取引先・勘定科目（中科目/小科目）を選択
- 証憑（請求書 PDF）添付
- 金額変更履歴の記録
- 仮取引先名（マスタに未登録）も入力可能 → 後日正規化

**受領BOX タブの使い方:**
1. 請求書を受領 → 受領日を記録
2. 証憑（PDF）を添付
3. 取引先・金額・科目を確認・修正
4. 確認できたら「準備完了 → 確定」へステータス変更
5. **「+ 新規請求書を追加」** ボタンから臨時タブの入力フォームを開いて新規追加も可能

**ヒント:** URL に `?tab=RECEIVED` などのクエリを付けて初期タブを指定できます（`FIXED` / `VARIABLE` / `TEMPORARY` / `RECEIVED`）。旧ブックマーク `/expense-box` は自動的に `/expenses?tab=RECEIVED` へリダイレクトされます。

### 5.4 売上入力

売上請求と入金消込を管理。

- **請求**: 取引先・金額・支払期日を登録
- **入金**: 入金日付と入金口座を登録（請求と紐付け）
- 入金遅延の検出
- 控除（源泉徴収・振込手数料相手負担など）の記録

### 5.5 原価支払

工事原価・仕入先への支払管理。

- 売上に紐づく原価支払を登録
- 支払予定日・支払口座
- 取引先銀行口座マスタから自動補完

### 5.6 給与入力

毎月の給与・賞与の処理。

- 給与グループ（社員・パート・役員等）単位で一括処理
- 支給合計・控除合計・差引支給額
- 社会保険・税金等の控除カテゴリ別に内訳記録
- FB データ（全銀協フォーマット）出力で銀行振込

### 5.7 グループ間入力

グループ会社間の取引（貸付・配当・サービス相殺など）を専用画面で登録。

- 一方の会社で出金、相手会社で入金として両方に同時計上
- グループ内取引の二重カウント防止

### 5.8 現金引出

ATM・窓口での現金引出を記録。

- 引出日付・口座・金額
- 引出後の小口現金箱への流入を追跡

### 5.9 借入管理

金融機関からの借入を管理。

- 借入契約マスタ（借入先・利率・期日）
- 返済予定表の自動生成
- 元金・利息の内訳記録

### 5.10 リース管理

リース契約（車両・機器）を管理。

- リース契約マスタ
- 月額リース料の自動生成
- 期日・残期間管理

### 5.11 納税予定表

法人税・消費税・地方税の納税予定を管理。

- 納税予定月の登録
- 引落・振込それぞれの支払方法
- 資金繰り表への自動反映

### 5.12 カード明細

法人クレジットカードの明細管理。

- 利用明細の登録・取込
- 引落日にまとめて資金繰り表へ反映

### 5.13 定期支払

毎月発生する定期取引のテンプレート登録（メニュー名: **定期支払**）。

- **頻度**: 毎月 / 隔月 / 四半期等
- **支払日ルール**: 25 日、月末、第 1 月曜日等
- **休日調整**: 支払日が休日の場合は前営業日/翌営業日に自動シフト（**日本祝日対応**）
- **金額タイプ**: 固定額 / 変動（前月実績から自動）/ 手動入力
- 登録するとボタン 1 つで翌月分が一括生成され、経費入力の「固定」「変動」タブに反映されます

### 5.14 マスタ管理

| マスタ | 内容 |
|---|---|
| **会社一覧** | 自社・グループ会社の登録（住所・代表者・法人番号・インボイス番号・**e-Tax 番号・資本金・経理担当者**・決算月など） |
| **会社グループ** | 会社をグループ化（持株会社単位等） |
| **銀行口座** | 各会社の銀行口座マスタ |
| **業種** | 業種マスタ（建設・広告等） |
| **売上項目** | 売上の内訳項目 |
| **取引先** | 取引先マスタ（顧客・仕入先） |
| **給与グループ** | 給与計算単位（正社員・パート等） |
| **勘定科目** | 勘定科目マスタ（中科目・小科目の階層） |
| **控除カテゴリ** | 給与控除カテゴリ（健康保険・税金等） |
| **設定** | システム設定 |

## 6. 標準的な業務フロー

### 6.1 月初のセットアップ

1. **マスタ管理** → 会社・口座・取引先・科目が登録済か確認
2. **定期支払** から固定取引を一括生成（経費・売上）
3. **資金繰り表** で月初残高・月末予測残高を確認

### 6.2 日々のオペレーション

#### 請求書を受領した時
1. **経費入力** → **受領BOX** タブで受領日を記録
2. 取引先・金額・科目を入力
3. 請求書 PDF を証憑として添付
4. 確認できたらステータスを「準備完了」へ

#### 支払い手続き
1. 資金繰り表で支払予定一覧を確認
2. 必要なら順序を入れ替え（ドラッグ&ドロップ）
3. FB データを出力 → 銀行へアップロード
4. 引落完了後にステータスを「確定」へ

#### 通帳照合
1. 銀行通帳を見ながら資金繰り表と突合
2. 一致した行で **「照合点設定」**（残高入力）
3. 差額が出れば自動でアラート表示

### 6.3 月末締め作業

1. すべての取引のステータスを「確定」に
2. 通帳と最終残高を突合
3. **資金繰り表** で対象月を選択 → 右上の「**月締め**」ボタンを押下（ADMIN のみ）
4. 月末残高が翌月の月初残高に自動繰越

## 7. よく使う操作

### 7.1 会社を切り替える
各ページ右上の会社プルダウンで切替。**ページごとに保持**されます。

### 7.2 月を切り替える
資金繰り表・受領BOX 等で `2026-05` 形式の月セレクター。

### 7.3 取引を翌月へ繰延べる
資金繰り表で行を選択 → **「繰延」** ボタン。月締め前のみ可能。

### 7.4 取引を並べ替える
行をドラッグ → 別の位置へドロップ。複数行は Shift+クリックで選択。

### 7.5 証憑を添付する
経費入力ページ（受領BOX タブ含む）の各行右側のクリップアイコンから PDF アップロード。

### 7.6 仮取引先を正規化
仮入力した取引先名 → **「正規化」** ボタンでマスタ済の取引先に紐付け。

### 7.7 月締めを解除する（ADMIN）
資金繰り表 → 対象月を選択 → 「月締め解除」→ 解除理由を入力 → 確定。

## 8. 用語集

| 用語 | 意味 |
|---|---|
| **資金繰り表** | 現金の出入りを時系列で一覧化した表 |
| **月締め** | その月の取引を確定し、編集不可ロックすること |
| **計上月** | その取引を「何月分」として計上するか（実出納日とは別概念） |
| **予定日** | 実際に出納される予定の日 |
| **実出納日** | 実際に出納が行われた日 |
| **照合点** | 通帳の実残高と一致した時点をマーキングする機能 |
| **証憑** | 取引の裏付けとなる書類（請求書・領収書 PDF 等） |
| **正規化** | 仮入力した取引先名を、マスタの正式取引先と紐付ける作業 |
| **FB データ** | 全銀協フォーマットの振込データファイル |
| **同日同時ルール** | 同日内では「引落 → 振込/移動 → 入金」順で並べる |
| **休日調整** | 支払予定日が祝日・土日の場合に前後の営業日へ自動移動 |

## 9. 困った時は

### よくあるケース

| 症状 | 対処 |
|---|---|
| ログインできない | パスワードを確認、ブラウザ Cookie をクリア |
| 「管理者のみ実行できます」 | ADMIN ロールを持つ人に依頼 |
| 「月締め後は金額変更できません」 | 月締め解除（ADMIN）が必要 |
| 残高が通帳と合わない | 照合点を使って差分を発見、未登録の取引を追加 |
| 画面が真っ白 | ブラウザのリロード（Cmd/Ctrl + Shift + R） |
| 取引先が見つからない | マスタ → 取引先 で新規登録 |
| FB データが作れない | 銀行口座マスタの「FB設定」を確認 |
| **資金繰り表に「帳票作成」ボタンが出ない** | 取引行のチェックボックスで 1 件以上を選択。月締め済みなら「月締め解除」が必要（5.2 参照） |
| **「選択した取引の種別が混在しています」エラー** | 帳票は「資金移動 / 振込 / 現金」3 種類だけ。**同じ動かし方の取引だけ**を選び直してください（5.2 参照） |

### サポート連絡先

システム管理者まで（社内）
